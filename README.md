# Ложные хорды левого желудочка сердца как внутренние механические ограничения

Исследовательский репозиторий для диссертационного проекта по физиологии, посвящённого механическому и функциональному картированию **ложных хорд (ложных сухожилий) левого желудочка (ЛЖ)** и их связи с геометрией, региональной механикой миокарда, показателями ЭКГ и общей физической работоспособностью.

---

## 1. Научная логика и гипотеза проекта

Центральная идея исследования состоит в том, что **ложные хорды ЛЖ следует рассматривать не просто как случайные анатомические находки, а как внутренние механические ограничения (internal mechanical constraints)**. Они могут действовать как внутриполостные механические стяжки, ограничивающие локальную деформацию, изменяющие характер сокращения смежных сегментов и перераспределяющие механическую нагрузку.

### Сдвиг парадигмы анализа:
* **От глобального к локальному:** Вместо поиска изменений общей фракции выброса (EF), которая при наличии хорд обычно остается сохранной, фокус смещен на региональную механику миокарда (strain/speckle tracking, механическая неоднородность сегментов ЛЖ, пространственные градиенты деформации).
* **От бинарного к механистическому:** Сравнение «хорда есть / хорды нет» признано малоинформативным. Вместо этого анализируется **пространственная архитектура хорд** и их предполагаемая биомеханическая роль в зависимости от точек прикрепления, направления и сложности сети.

## 3. Ключевые научные результаты исследования

На основе статистического анализа выборки пациентов ($n \approx 200$) получены следующие ключевые результаты:

### 3.1. Фенотипы нагрузочно-геометрической адаптации ЛЖ
С помощью кластеризации K-Means ($k=3$) по гемодинамическим и геометрическим признакам ($\Delta$САД, $\Delta$SWS, индексы сферичности) были выделены три паттерна ответа сердца на нагрузку:
1. **Геометрически-сферичный фенотип ($n=9$):** ЛЖ адаптируется за счет округления формы (высокие индексы сферичности в систолу и диастолу) при умеренном уровне механического стресса.
2. **Низконагрузочный менее сферичный фенотип ($n=10$):** наиболее «спокойный» профиль без выраженного прироста АД, механического напряжения и изменения геометрии ЛЖ.
3. **Стресс-доминантный фенотип ($n=7$):** максимальный прирост механического напряжения стенки ($\Delta$SWS) и артериального давления без перестройки геометрии миокарда в сферическую форму.

#### Физиологическая «цена адаптации»
Анализ показателей механической неоднородности продольного смещения миокарда (`DICOR CV ССОУ`) показал, что **стресс-доминантный фенотип требует наибольшей цены адаптации**: вариабельность продольного смещения у таких пациентов составила **41.6%** по сравнению с 22.9% и 18.8% в геометрически-нейтральных и сферичных фенотипах.

### 3.2. Механистическая классификация ложных хорд
Разработана новая патофизиологическая классификация, разделяющая пациентов по типу создаваемых хордами ограничений:

| Группа хорд | Название класса | Анатомическая характеристика | Предполагаемый биомеханический смысл |
| :--- | :--- | :--- | :--- |
| **Класс 1** | **Local transverse / low-angle** | Локальная поперечная или низкоугловая хорда | Локальное ограничение смещения соседних сегментов миокарда |
| **Класс 2** | **Single long oblique** | Одиночная протяженная косая хорда | Межрегиональная хордальная связь удаленных зон ЛЖ |
| **Класс 3** | **Double transverse** | Две поперечные хорды без длинных косых | Усиленное локальное поперечное стягивание |
| **Класс 4** | **Chord network** | Сложная многокомпонентная сеть хорд | Распределенная система внутренних механических ограничений |

---

### 3.3. Влияние хордальной архитектуры на структуру и деформацию ЛЖ
Формальный дисперсионный анализ (ANOVA, Welch ANOVA, Kruskal-Wallis) показал, что геометрическая сферичность ЛЖ напрямую не зависит от класса хорд ($p > 0.8$). Однако обнаружены выраженные структурно-механические ассоциации:
* **Индекс массы миокарда ЛЖ (ИММЛЖ):** Обнаружен достоверный групповой сигнал (ANOVA $p=0.036$, Kruskal $p=0.049$). Наибольшая масса миокарда характерна для группы *Single long oblique chord* (в среднем на **+31.4 г/м²** выше по сравнению с локальной поперечной хордой).
* **Неоднородность деформации ЛЖ (CV деформации):** Сетевая архитектура (*Chord network*) ассоциируется со статистически значимым повышением вариабельности деформации миокарда по сравнению с одиночной косой хордой (разница медиан составляет **+8.39%**, Welch-Holm post-hoc $p=0.013$).

### 3.4. Влияние на аэробную работоспособность (VO₂max)
Для оценки функциональной «цены» хордального аппарата построена регрессионная OLS-модель связи механистических классов ЛХ с уровнем абсолютного $VO_2max$ с поправкой на базовые демографические и антропометрические факторы (пол, возраст, площадь поверхности тела — $BSA$).

Модель показала высокую статистическую значимость ($p = 0.00013$, $R^2 = 0.339$). Группа хордальной архитектуры сохраняет независимую связь с $VO_2max$ после поправок ($p = 0.0396$). 

#### Результаты регрессионных контрастов (референс — локальная поперечная хорда):
* **Две поперечные хорды (Double transverse):** Ассоциируются с наиболее выраженным снижением аэробной способности миокарда (коэффициент регрессии **$-17.45$ мл/мин**, $p < 0.001$).
* **Сеть хорд (Chord network):** Также достоверно снижает работоспособность (коэффициент **$-10.28$ мл/мин**, $p = 0.005$), но при этом отличается широкой индивидуальной вариабельностью результатов.
* **Одиночная косая хорда (Single long oblique):** Не имеет статистически значимых функциональных отличий от референсной группы.

## 5. Воспроизведение результатов (Quick Start)

Проект использует менеджер пакетов `uv` для быстрого и воспроизводимого управления зависимостями.

### Шаг 1. Установка окружения и зависимостей
Убедитесь, что у вас установлен `uv` (или выполните `pip install uv`), после чего в корне проекта выполните:
```bash
uv sync
```

### Шаг 2. Активация виртуального окружения
* **Windows (PowerShell):** `.venv\Scripts\activate`
* **Linux/macOS:** `source .venv/bin/activate`

### Шаг 3. Запуск пайплайна валидации данных
Выполните первичный аудит пропущенных значений и проверку типов данных:
```bash
python scripts/validate_data.py
```
Отчёты будут сохранены в `output/diagnostics/` и `output/tables/`.

### Шаг 4. Полный запуск DVC-пайплайна
Если настроена система контроля версий данных (DVC):
```bash
dvc repro
```
Данная команда последовательно выполнит очистку данных, извлечение признаков, расчет кластеров, OLS-моделирование и экспорт всех таблиц и графиков в папку `output/`.

## 6. Безопасность данных и кодекс исследований

Проект работает с конфиденциальными медицинскими данными:
1. **Никаких сырых данных в Git:** Директория `data/raw/` внесена в `.gitignore` и заблокирована от публикации.
2. **Анонимизация:** Все участники идентифицируются исключительно по случайному коду `study_id`.
3. **AI-ограничения:** Настроен файл `.aiexclude` для предотвращения утечки конфиденциальной информации в контекст индексации языковых моделей.
